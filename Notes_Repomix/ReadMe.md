# Шпаргалка: локальная LLM (Qwen 27B + Zoo Code) в мульти-репозиторном .NET 10 проекте

Эта инструкция описывает полный пайплайн подготовки сжатого контекста из нескольких `.sln` (лежащих в разных репозиториях на одном диске)
для локальных моделей среднего размера.

---

## 1. Правила эффективной работы с Qwen 27B

* **Целевой размер контекста: 10 000 – 20 000 токенов** (~1500–2500 строк сжатого кода). После 30–40k токенов у 27B-моделей падает внимание («lost in the middle») и скорость генерации.
* **Отключайте Thinking / CoT** на рутинных задачах (CRUD, Kafka-консьюмеры, маппинг), чтобы модель не сжигала 60% бюджета на внутренний монолог.
* **Ограничьте `num_ctx` до 32k** в настройках движка (Ollama / LM Studio / llama.cpp), чтобы модель не уходила в оперативную память (RAM).
* **1 задача = 1 чистый чат.** Не накапливайте историю решённых задач в одном диалоге.
* **Принцип срезов:**
  * Окружающие проекты (контракты, DTO, интерфейсы сервисов и репозиториев) передаются **со сжатием через Repomix**.
  * Файл, который вы редактируете прямо сейчас, передаётся **целиком (без сжатия)**.

---

## 2. Настройка окружения (один раз)

### Шаг 1. Глобальная установка Repomix

Устанавливается глобально, чтобы работать офлайн и без задержек `npx`:

```bash
npm install -g repomix
```

### Шаг 2. Создание глобального C#-скрипта (`C:\Tools\pack-sln.cs`)

Вынесите скрипт за пределы репозиториев (например, в `C:\Tools\pack-sln.cs`). Это изолирует его от `Directory.Build.props` ваших проектов и избавит от необходимости править `.gitignore`.

Скрипт использует фичу .NET 10 (file-based apps) для запуска одного `.cs`-файла без `.csproj`, автоматически находит общий корень для всех `.sln` на одном диске, собирает версии NuGet-пакетов, упаковывает код в буфер обмена и удаляет за собой все временные файлы.

**`C:\Tools\pack-sln.cs`**:

## 3. Команды для ежедневной работы

Запускать можно **из любой папки** в терминале (флаг `--file` обязателен, чтобы `dotnet run` не пытался собрать текущий проект):

```bash
# 1. Собрать контекст по списку defaultSlns с фильтрацией нужных проектов (рекомендуется)
dotnet run --file C:\Tools\pack-sln.cs -- --project "Billing|Contracts|Kafka"

# 2. Передать конкретные .sln файлы вручную через запятую
dotnet run --file C:\Tools\pack-sln.cs -- --sln "D:\Repo1\A.sln,D:\Repo2\B.sln" --project "Contracts|Application"

# 3. Задать свой фильтр отслеживаемых NuGet-пакетов
dotnet run --file C:\Tools\pack-sln.cs -- --project "Orders" --nuget "Confluent|Dapper|MediatR"
```

*Результат автоматически попадает в буфер обмена (`--copy`), временные файлы на диске не остаются.*

## 4. Справочник используемых флагов Repomix

| Флаг | Назначение | Эффект |
| :--- | :--- | :--- |
| `--compress` | Сжимает код через Tree-sitter, вырезая тела методов (`⋮----`). | Оставляет только классы, DTO и сигнатуры интерфейсов. |
| `--remove-comments` | Удаляет `//`, `/* */` и XML-документацию `/// <summary>`. | Срезает до 30% объёма в C#-файлах. |
| `--remove-empty-lines` | Удаляет пустые строки. | Уплотняет текст, экономит токены. |
| `--no-directory-structure` | Убирает ASCII-дерево папок из начала XML. | Убирает дублирование путей (пути есть в тегах `<file path="...">`). |
| `--no-file-summary` | Убирает вводную справку Repomix из начала файла. | Экономит ~300 токенов на стандартном предисловии. |
| `--copy` | Копирует результат сразу в буфер обмена. | Готово к мгновенной вставке через `Ctrl+V` в Zoo Code. |

## 5. Полезные диагностические команды

* **Узнать прямые зависимости конкретного проекта (глубина 1):**

```bash
dotnet list src/Orders.Application/Orders.Application.csproj reference
```

* Найти топ-10 самых «жирных» по токенам файлов в директории (чтобы добавить их в --ignore):

```bash
repomix --compress --include "src/Orders.Application/**/*.cs" --top-files-len 10
```

* Скачать полную офлайн-документацию Repomix в один Markdown-файл:

```bash
repomix --remote yamadashy/repomix --include "website/client/src/en/guide/**/*.md,README.md" --style markdown -o repomix-docs.md   
```

## 6. Рабочий цикл в Zoo Code (Workflow)

1. Запустите `dotnet run --file C:\Tools\pack-sln.cs -- --project "НужныйДомен|Contracts"`
2. Убедитесь в консоли, что Total Tokens уложился в 10 000 – 20 000 токенов.
3. Откройте новый чистый чат в Zoo Code.
4. Нажмите Ctrl+V (вставится XML-слепок окружения из буфера обмена).
5. Ниже вставьте полный код 1 целевого файла, который вы сейчас редактируете.
6. Напишите короткое ТЗ:«Выше даны контракты, DTO и сигнатуры интерфейсов нужных сервисов. Ниже — полный код целевого класса OrderCancelledConsumer.cs. Реализуй обработку события OrderCancelled:. Используй только методы из переданных интерфейсов. Выведи только изменённый класс».

*(Примечание: в строках с интерполяцией `\$"..."` внутри C#-кода выше уберите обратный слеш перед `$` при копировании в `pack-sln.cs` — он добавлен только для корректного экранирования внутри Markdown-блока).*

Всё готово к использованию!
